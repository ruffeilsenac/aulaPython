Atividade – Sistema de pedidos de uma lanchonete

Contexto: uma lanchonete deseja informatizar o atendimento, permitindo que os clientes escolham produtos, informem quantidades e acompanhem o valor total do pedido.

Enunciado:
Crie um sistema de pedidos com o seguinte cardápio:
Código	Produto	Preço

1	Hambúrguer	R$ 18,00
2	X-Bacon	R$ 22,00
3	Batata frita	R$ 12,00
4	Refrigerante	R$ 7,00
5	Finalizar pedido	—


Regras:
•	O sistema deverá apresentar o cardápio enquanto o pedido não for finalizado.
•	O cliente poderá escolher vários produtos.
•	Para cada produto, deverá informar a quantidade desejada.
•	O sistema deverá calcular o subtotal de cada escolha.
•	Ao finalizar, deverá apresentar o valor total do pedido.
•	Não permitir quantidades menores ou iguais a zero.
•	Informar quando o cliente escolher um código inválido.
